# Contracts

All public packages evolve in lockstep under `CONTRACT_VERSION`. The current contract is experimental and additive evolution is preferred; SQLite changes require an explicit migration and future schema versions are rejected.

- Kernel: append-only typed events with global and per-stream order. Events are required by default; `ignorable: true` explicitly permits an unfamiliar reader to skip an informational event. The kernel does not name Goal, Wake, Mailbox, or Action.
- Session: format v1 normalized user/assistant/tool/request/compaction events; format 0 upgrades in memory, future formats and unknown required events fail closed. `replaySession()` derives the model-visible transcript and interrupted open tool calls become explicit `unknown` outcomes.
- Execution modules: six rebuildable standard projections; event and projection mutations are atomic. Goal contains identity, hierarchy, objective, nullable Root observation/verification methods, ownership, the `active|paused|blocked|complete` phase, and revision. Child Goals require both methods. Atomic delegation commits Child Goal, Work Record, decision fact, Mail, and queued Wake in one transaction; reassignment transfers Work Record write authority. Completion requires reason and current-revision evidence. Metrics remain optional registrations.
- Runner: process-isolated request/result protocol with immutable Turn source and optional Goal binding, normalized Session forwarding, fencing, ordinary response or Goal Handoff, exact request capture, and Runner-owned local execution. Every Pi Agent receives `read`, `write`, `edit`, and `bash`; Goah RPC tools remain role-scoped. Resource policy is not part of the core request/result contract.
- RPC: request/response IDs over the runner pipe; supervisor validates the active lease and role capability before every read or mutation. The interactive CLI uses a separate local control socket owned by the resident Supervisor, which remains the only SQLite writer.
- Load: structured projections are deterministically rendered as a short Markdown Active Context with source event sequences; the final value is recorded by `request.prepared`.
- Work Record: one virtual Markdown document per Goal, stored as immutable versions plus a current projection. Organization-wide reads, history, diff, and search are available; owner/parent-owner updates use revision CAS and Ledger evidence. Goal-bound Turn completion requires a record version authored in that Turn.
- Handoff: ordinary Turns have none. Goal Handoff contains Goal/revision, Work Record revision, outcome, evidence, Mail, and next Wake. Legacy narrative Handoffs remain readable.
- Legacy working memory: existing `memory:{agent}` streams remain readable and migrate into Work Records. CEO and Child Goal Agents no longer receive `memory.append`; verifier/audit memory remains independent.
- CEO operating layer: `ceo` is the sole normal Human-facing Agent. Ordinary interaction is unbound. Durable Human intent may call `create_goal` or `work_on_goal`, after which strict Goal policy applies. The roster is derived from Goal/Wake/Schedule/Handoff facts; stale Child revisions cannot begin gated actions; and an active Root cannot hand off without Child motion, a review, a blocker, or a Human request.
- Connector: process-isolated capability manifest declaring idempotency, query behavior, retry policy, and generic approval risk. Payload policy belongs to the connector or an extension.

Third-party ledgers should run `assertLedgerConformance()` from `@goah/cli/testkit`. All public framework APIs ship in the single `@goah/cli` distribution; source workspace names are not independently published from 0.3 onward.
