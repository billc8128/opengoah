# Contracts

All public packages evolve in lockstep under `CONTRACT_VERSION`. The current contract is experimental and additive evolution is preferred; SQLite changes require an explicit migration and future schema versions are rejected.

- Kernel: append-only typed events with global and per-stream order. Events are required by default; `ignorable: true` explicitly permits an unfamiliar reader to skip an informational event. The kernel does not name Goal, Wake, Mailbox, or Action.
- Session: format v1 normalized user/assistant/tool/request/compaction events; format 0 upgrades in memory, future formats and unknown required events fail closed. `replaySession()` derives the model-visible transcript and interrupted open tool calls become explicit `unknown` outcomes.
- Execution modules: five rebuildable standard projections; event and projection mutations are atomic. Goal contains identity, hierarchy, objective, a nullable textual observation method, ownership, the `active|paused|blocked|complete` phase, and revision. Atomic delegation commits the child objective/observation pair, decision fact, mail, and queued Wake in one transaction; atomic reassignment also notifies both owners and suppresses the previous owner's queued Wake. Completion requires reason and current-revision evidence. Metrics remain optional registrations.
- Runner: process-isolated request/result protocol, normalized Session forwarding, fencing, structured handoff, exact request capture, and runner-owned local execution. Every Pi Agent receives `read`, `write`, `edit`, and `bash`; Goah RPC tools remain role-scoped. Resource policy is not part of the core request/result contract.
- RPC: request/response IDs over the runner pipe; supervisor validates the active lease and role capability before every read or mutation. The interactive CLI uses a separate local control socket owned by the resident Supervisor, which remains the only SQLite writer.
- Load: structured projections are deterministically rendered as a short Markdown Active Context with source event sequences; the final value is recorded by `request.prepared`.
- Handoff: observations, results, next steps, optional blocker/material marker, mail, and next wake.
- Working memory: each Agent owns a `memory:{agent}` event stream of `memory.appended` facts appended through the role-scoped `memory.append` RPC. Active Context injects the newest notes within a character budget as an advisory tail with `[event:seq]` provenance; the stream itself is never compacted and remains queryable evidence. Handoff stays the structured milestone record; memory carries procedural knowledge, hypotheses, and abandoned approaches across wakes without provider session state.
- CEO operating layer: the `ceo` identity is the default sole user-facing owner for root Goals. `goah` starts or attaches an interactive CEO. Its first-root policy explores the current directory and proposes an observation method for human confirmation; its roster is derived from Goal/Wake/Schedule/Handoff facts; stale child revisions cannot begin gated actions; and an active root cannot hand off without child motion, a review, a blocker, or a human request.
- Connector: process-isolated capability manifest declaring idempotency, query behavior, retry policy, and generic approval risk. Payload policy belongs to the connector or an extension.

Third-party ledgers should run `assertLedgerConformance()` from `@goah/cli/testkit`. All public framework APIs ship in the single `@goah/cli` distribution; source workspace names are not independently published from 0.3 onward.
