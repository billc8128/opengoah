## Highest-impact findings and fixes

1. Overview repeated handoff seq, next wake, health, and runtime metadata across the tree, rail, trajectory, and sidebar. Removed duplicate seq and local-host metadata, reduced the trajectory preview to three moments, and hid the recovery section when healthy.
2. The old wake-scoped trace gave each turn marker its own empty vertical band. Turn labels now share the first row of the turn, and row height is reduced without hiding tool payload previews.
3. Work Ledger expanded every handoff into three large bordered regions. Records are now compact summaries with one result and one next step; details use progressive disclosure.
4. Agents embedded expanded Work Ledger cards inside the agent inspector. Agent records now use the same compact summary rows, while Threads remain a direct route to the trace.
5. Every page repeated a product kicker, long explanatory sentence, current seq, agent count, hostname, and connection detail. Removed these where they did not change the user’s decision.
6. The Overview tree depended on a wide three-column branch diagram and compressed unpredictably beside the attention rail. Replaced it with a width-safe vertical hierarchy and removed the right rail entirely. Its useful information now lives at the point of use: CEO contact in the goal header, approval state under the observation, and wake time on each agent row.

## Removed complexity

- Sidebar event seq and agent count.
- Sidebar hostname and duplicate connection description.
- Healthy recovery callout.
- Overview handoff seq per agent.
- Duplicate Work Ledger links in the Overview trajectory.
- Expanded-by-default work record sections.
- Empty turn spacer rows.
- Repeated `Goah Console` page kicker.
- Overview right rail and its duplicate next-wake, attention, recovery, and quick-action sections.
- Horizontal branch geometry and equal-width agent columns.

## Accessibility and verification

- Primary navigation, work record disclosure, Ledger modes, Agent selection, Thread opening, and CEO composer remain keyboard-addressable buttons.
- Work record summaries expose `aria-expanded`.
- Desktop and 390px mobile have no document-level horizontal overflow; the detailed trace table scrolls within its own region on mobile.
- Browser console is clean.
- Screenshot inspection cannot prove full screen-reader order or every contrast ratio; those require a dedicated automated/manual accessibility pass.
